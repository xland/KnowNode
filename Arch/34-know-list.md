# 34 · 知识列表面板 KnowList

代码位置：`UI/src/KnowList/`（`KnowList.html + .scss + .ts`）。

## 面板结构

- 面板**顶部有一块类似标题栏的区域**：
  - **左侧**：文字「**知识列表**」；
  - **右侧**：一个**增加知识的图标按钮**（`icon icon-add`）。
- 下方是**知识列表**（每一项是一个"知识"：历史知识、编程知识、文学知识……）。

```
┌────────────────────────────┐
│ 知识列表              [ ＋ ] │  ← 顶部标题栏区（左文字 / 右 icon-add）
├────────────────────────────┤
│ 历史知识                    │
│ 编程知识                    │
│ 文学知识                    │
└────────────────────────────┘
```

## 新建知识

1. 点击顶部右侧的 **`icon icon-add`** 按钮；
2. 在**按钮正下方**浮出一个小面板（**DOM 结构**实现，不是原生对话框）——**没有遮罩**，
   内容就三样：**一个输入框 + 确定 + 取消**（不要标题栏、不要说明文字，见 Dialog 的锚定形态）；
3. 输入框填**知识名称**（placeholder 提示"知识名称"）；
4. **确定 / 回车** → 创建该知识；**取消 / Esc / 点到别处 / 再点一次加号** → 收起。

## 修改 / 删除知识

- 在**列表项上点击右键** → 弹出**菜单**，菜单项：
  1. **修改知识名称**
  2. **删除知识**

## 与画布的关系

- 点击列表中的某个知识 → `KnowNet` 加载该知识的节点（见 [31-content-box.md](./31-content-box.md)）。
