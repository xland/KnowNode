## P5 · 架构替代 / 不适用（无需照搬）

这些是 WebView2 架构特有的东西，DUI 版已经用不同方式实现，不需要补。

- [-] 25 个 WebView2 IPC method：DUI 版 C++ 直接调用 DB/UI，无 IPC 桥
- [-] `maximize` / `restore` 事件推送：DUI `Window::OnStateChanged()` 替代
- [-] `https://app.localhost/*` 虚拟域名与内嵌 dist：全部 UI 原生，无外部资源
- [-] File System Access 图片目录句柄：DUI 剪贴板 / 拖放 + data URI 替代
- [-] `images/` 目录与图片 URL 重写：图片以 data URI 内联在 `RichDoc` JSON 中
- [-] HTML 详情存储：`know_detail.content` 改存 `RichDoc` JSON；不兼容老数据（已确认新产品）

## 已完成基线（当前版本已有）

- **窗口外壳**：无边框窗口、标题栏拖拽、三按钮 + DUI 内置图标、最大化/还原图标切换、关窗 flush
- **三栏结构**：知识列表 / 画布 / 详情面板，两条可拖拽 splitter（列表 4px、详情展开时 4px）；列表 300 / 画布 500 / 详情 600 最小宽度约束，宽度经 `setting` 表持久化并启动恢复
- **知识列表**：新建、重命名、删除、右键菜单两项、创建时间排序、自动选中、删当前项后选第一行
- **画布**：节点/连线绘制、标题、6 色标记、单击切详情、右键建节点/关联/改色/删除、拖动节点、滚轮中心缩放、空白拖拽平移、实时搜索高亮、坐标与颜色落库
- **详情**：节点/连线/知识三类对象切换、300ms 防抖保存、切换/关窗 flush
- **编辑器**：标题/正文/列表/引用/代码/图片 6 个工具按钮（图标沿用原项目）、图片粘贴/拖入、代码块基础插入
- **数据**：五张 SQLite 表完全复用、数据目录一致、单 exe 内嵌图标与 SVG 资源
