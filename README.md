# KnowNode 知点

**节点化个人知识管理工具。**

人脑海里的知识不是分门别类的目录树，而是一张网：最小单位是一个**知识节点**，节点与节点之间有**关联**，众多节点通过关联织成一张网。KnowNode 就是照这个形状做的——先有知识（一张网的入口），再在网里摆节点、连关联、写详情。

所有内容都保存在**本机**，不依赖网络。

## 一、知识列表（左栏）

一个列表项就是一个**知识**，例如「历史知识」「编程知识」「文学知识」。点某个知识，中间的画布就加载它的那张网。

| 操作 | 做法 | 说明 |
| --- | --- | --- |
| 新建知识 | 点列表右上角的 **＋** | 在按钮下方浮出一个输入框，填名字后确定（回车也行）；Esc、点别处、再点一次加号都收起 |
| 重命名 | 在列表项上**右键 → 修改知识名称** | |
| 删除 | 在列表项上**右键 → 删除知识** | 删掉的知识连同它下面的节点与连线一起没了 |
| 切换 | 单击列表项 | 画布换成这个知识的网 |

## 二、知识节点网络画布（中栏）

### 节点

| 操作 | 做法 |
| --- | --- |
| 新建节点 | 在画布**空白处右键 → 新建知识节点**，节点就落在右键的那个位置 |
| 新建关联节点 | 选中一个节点后，点它右侧的 **＋** 按钮，或按 **Tab** —— 新节点出现在它右边并**自动连好线**，随即进入标题编辑，可以一路敲下去 |
| 改标题 | **双击节点**就地改（回车 / 失焦提交，Esc 放弃）。标题最多 **36 个字符**，空白的会显示成「未命名」 |
| 摆放 | **拖节点中间**随便挪，位置会记住 |
| 标记色 | **右键节点**，弹出一行六个颜色按钮（红橙黄绿蓝紫）。点一个就着色，**再点一次当前那个色 = 取消标记** |
| 删除 | 选中后按 **Del**，或 **右键节点 → 删除节点**；多选时删整批（菜单会写成「删除选中的 N 个节点」） |

### 连线（关联）

| 操作 | 做法 |
| --- | --- |
| 连一条线 | 从**节点的边缘**往外拖（边缘有约 6px 的热区），拖到另一个节点上松手；**在空白处松手 = 取消** |
| 标记色 | 右键连线，同样是那一行六个颜色按钮 |
| 删除 | 选中连线后按 **Del**，或 **右键连线 → 删除连线**。删节点时它的连线跟着一起删 |
| 写详情 | 单击连线选中它，详细内容面板里可以给**这条关联**写内容 |

### 选中与多选

- **单击节点** = 只选它一个；**单击空白处** = 取消选中。
- **Ctrl + 单击节点** = 加选 / 取消这一个（多选的第二种方式）。
- 在空白处**按住拖出一个框** = 框选，与框交叠的节点一起选中（擦到一点就算）。
- 多选之后：拖其中一个，**整批一起移动**；按 **Del** 或右键删除，**整批一起删**；状态栏显示「已选中 N 个节点」。
- 多选时不展开详细内容面板（详情是给"某一个对象"用的）。

### 看与找

| 想做什么 | 怎么做 |
| --- | --- |
| 放大 / 缩小 | **Ctrl + 滚轮**（以鼠标位置为锚点，光标下那个点不动） |
| 上下移动画布 | 直接**滚滚轮**（就是滚动条的用法） |
| 平移画布 | 按住 **Ctrl** 或 **空格** 再拖空白处；不按则拖出的是选框 |
| 搜索节点 | 左上角搜索框输入标题片段后**回车**（或点搜索图标）：命中的第一个节点会被**摆到视口正中并选中**；一个都没命中会浮一行提示，2 秒后自己消失。搜索框只在打开了某个知识时出现 |

## 三、详细内容（右栏，可收起）

一个富文本编辑区，内容随当前选中的对象变：

| 当前对象 | 面板内容 |
| --- | --- |
| 选中（单个）节点 | 这个知识点的详情 |
| 选中连线 | 这条关联的详情 |
| 没选中 / 多选 / 点空白 | **这个知识整体**的描述 |

- **编辑即存**，不用点保存；关面板、切换知识时会先把没写完的内容落盘，不丢字。
- **标题不在这里改**——改标题只有画布上双击节点那一个入口。
- 工具栏提供：撤销 / 重做、标题级别、字体、字号、粗体、斜体、下划线、删除线、上标、下标、文字颜色、背景色、引用、对齐、行高、项目符号、编号列表、插入链接 / 移除链接、**插入图片**、代码块、水平线。
- **图片**：直接粘贴或拖进编辑区即可，会自动存到本机数据目录，正文里只留一个文件名，重开也还是好图。插入后可以拖拽改显示大小。

---

## 四、状态栏与窗口

- **状态栏左侧**：当前选中的是哪个节点（多选时显示「已选中 N 个节点」）；**右侧**：当前知识一共有多少个节点。
- **标题栏**：最小化 / 最大化 / 还原 / 关闭，拖动标题栏可以移动窗口。
- **窗口边缘**：从窗口的四条边与四个角拖拽可以改变窗口大小（最大化时自动失效）。

## 快捷键速查

| 按键 | 作用 |
| --- | --- |
| 双击节点 | 就地改标题 |
| 改标题时回车 / Esc | 提交 / 放弃 |
| 改标题时 Tab | 提交当前标题，接着新建关联节点并继续编辑（连打） |
| Tab（选中单个节点） | 新建关联节点（等同于点 ＋） |
| Del | 删除选中的节点（整批）或连线 |
| Ctrl + 单击节点 | 加选 / 取消这一个 |
| Ctrl 或 空格 + 拖空白 | 平移画布 |
| 拖空白 | 框选 |
| Ctrl + 滚轮 | 缩放画布 |
| 滚轮 | 上下移动画布 |
| 搜索框内回车 | 搜索并把命中的节点摆到视口中心 |
| 右键 | 节点 / 连线 / 空白各自的菜单 |
